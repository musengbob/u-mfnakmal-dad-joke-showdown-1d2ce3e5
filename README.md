One dad joke, told the way a father would tell it at the dinner table:

> I asked the librarian if the library had books on paranoia. She whispered, 'They're right behind you.'

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the joke to `output/entry.txt` (102 code points, within the 1–200 limit) and verifies the output is byte-identical to the joke, exiting non-zero otherwise. No dependencies; Node 22.18+.
